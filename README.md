# javascript-lotto-precourse

## 로또

### 기능목록

- 구입 금액에 해당하는 만큼 로또를 발행할 수 있다. ( 로또 번호는 오름차순으로 정렬 )
- 사용자가 구매한 로또 번호 중에 당첨 번호와 일치하는 숫자가 몇 개 있는지 알 수 있다.
- 사용자가 구매한 로또 번호 중에 보너스 번호와 일치하는 숫자가 있는지 확인할 수 있다.
- 사용자가 구매한 로또의 등수를 알 수 있다.
- 사용자가 구매한 로또들의 당첨 내역을 집계할 수 있다.
- 사용자의 수익률을 구할 수 있다.
  - 사용자의 총 수익을 구할 수 있다.
  - 사용자의 수익률을 구할 수 있다. ( 수익률은 소수점 둘째자리에서 반올림 )

### 입력 요구 사항

1. 로또 당첨 번호

- 로또 번호의 각 숫자들은 양의 정수이다.
- 로또 번호의 각 숫자의 범위는 1~45까지이다.
- 로또 번호의 각 숫자들은 중복되지 않아야 한다.

2. 보너스 번호

- 보너스 번호 숫자는 양의 정수이다.
- 보너스 번호 숫자는 숫자의 범위는 1~45까지이다.
- 보너스 번호 숫자는 당첨 번호 숫자들과 중복되지 않아야 한다.

3. 로또 구입 금액

- 로또 구입 금액은 양의 정수이다.
- 로또 구입 금액은 1,000원 단위이다.
- 로또 구입 금액은 100,000원을 넘을 수 없다.
